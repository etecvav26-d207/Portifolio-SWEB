# 📚 Pesquisa - TinyDB (MIT App Inventor)

Este repositório contém a atividade de pesquisa sobre o componente **TinyDB** do **MIT App Inventor**, desenvolvida para a disciplina de **Desenvolvimento de Dispositivos Móveis (SWEB)

O trabalho apresenta os principais conceitos sobre o TinyDB, seu funcionamento, aplicações práticas, diferenças em relação ao TinyWebDB e boas práticas para armazenamento local de dados em aplicativos.
