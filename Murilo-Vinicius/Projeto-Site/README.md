# Projeto Site - EcoBites

Este repositório contém o planejamento e a proposta para o desenvolvimento do site "EcoBites", focado em alimentação saudável e sustentável, com serviço de marmitas fitness.

## Organização do Repositório

- `planejamento/`: Documentos detalhados de planejamento do site.
- `imagens/`: Imagens e recursos visuais utilizados no projeto.
- `logo/`: Arquivos relacionados ao logo da empresa/site.
- `referencias/`: Quaisquer referências externas utilizadas.
